What is SDLC?

The Software Development Life Cycle (SDLC) is a process for planning, creating, testing, and deploying software applications.


Building A House Example:

  1. Planning: Plan what to build
  2. Design: Draw blueprints
  3. Implementation: Build the house
  4. Testing: Check if it meets the requirements
  5. Deployment: Move in
  6. Maintenance: Fix later problems
